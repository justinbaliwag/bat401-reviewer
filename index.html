Google Colab Data Cleaning Pipeline (Steps 1 to 12)

Every snippet corresponds exactly to the BAT 401 reviewer.

Steps 1 & 2

Import & File Loading

Import pandas and read file paths in Google Colab:

import pandas as pd

# Read Excel
df = pd.read_excel('/content/data.xlsx')

# Read CSV
df = pd.read_csv('/content/data.csv')
Steps 3, 4, 5

Dataset Inspection

View rows, structural metadata, and descriptive statistics:

df.head()       # First 5 rows
df.info()       # dtypes, memory, null count
df.describe()   # Stats table
Step 6

Correcting Data Types

Nullable integer casting so ID columns allow missing values:

df['Customer_ID'] = df['Customer_ID'].astype('Int64')
Steps 7, 8, 9

Duplicates Handling

Count, view with keep=False, and drop duplicates:

# Count
print("The total number of duplicates:", df.duplicated().sum())

# Display all duplicates including first
duplicate = df[df.duplicated(keep=False)]

# Drop in place
df.drop_duplicates(inplace=True)
Steps 10 & 11

Missing Values & Dropping Empty Columns

Count nulls and drop columns containing only nulls:

# Count nulls per column
df.isnull().sum()

# Drop columns with 100% missing values
df.dropna(axis=1, how='all', inplace=True)
Step 12

Handling Missing Values (Imputation)

Use mean for numerical data and mode for categorical text:

# Numerical Imputation
df['Amount'].fillna(df['Amount'].mean(), inplace=True)

# Categorical Imputation
df['Payment_Method'].fillna(df['Payment_Method'].mode()[0], inplace=True)

Tableau Public Canvas Interface Breakdown

Columns Shelf:

Organizes data horizontally (X-axis). Category placed here creates columns for Technology, Furniture, and Office Supplies.

Rows Shelf:

Organizes data vertically (Y-axis). SUM(Sales) placed here sets bar heights representing total revenue.

Filters Shelf:

Filters data to show only specific conditions without altering raw data (e.g. Region = CALABARZON).

Marks Card:

Controls visual properties: Color (categories), Size, Label (exact text like ₱71,500), Detail, and Tooltip.

Tableau Groups

Combines multiple data members into a single category.

Procedure to Create a Group (Reviewer P.3):
  1. Right-click Product Name in Data pane.
  2. Select Create > Group.
  3. Select all products belonging to the same brand (e.g., Xerox).
  4. Click Group and rename it XEROX.
  5. Repeat for other brands.
  6. Rename the new group field BRANDS.
  7. Drag BRANDS and Product Name into the Rows shelf.

Tableau Sets (Top 5 & In/Out)

Defines a subset of data based on conditions or Top N parameters, classifying into IN or OUT.

Procedure to Create Top 5 Set (Reviewer P.3):
  1. Right-click Sub-Category in Data pane.
  2. Select Create > Set.
  3. Open the Top tab.
  4. Select By Field, then choose Top 5 by SUM(Sales).
  5. Click OK to create the Set.
  6. Drag Set to Color on Marks card to distinguish In vs. Out.
  7. Drag Set to Label to display In and Out above bars.
